# 실행 계획

최종 갱신: 2026-08-01

## 1. 현재 기준

상황판은 실행계획 변환 과정에서 누락된 기능으로 확인되었다. 원래 제품 단계 구분을
유지해 숫자 중심 v1은 Round 3.5, 그래프·시장·거시 지표 중심 v2는 Round 5.5에
편입한다.

현재 구현은 Round 3의 정부 공고 수집과 규칙 기반 정보가치까지 완료한 상태다. AI
요약·깊이 분류, 기업 명부·후보가 남아 있으므로 Round 3.5는 이 선행 작업을 닫은 뒤
착수한다.

### 문서 정합성 주의

첨부 개정안이 참조한 `PRD-startup-intelligence-archive.md`와 현재 저장소의
`docs/PRD.md`는 상황판 범위가 다르다. 현재 `docs/PRD.md`는 Phase 1 비목표로
“시장·거시 지표 상황판”을 적고 있다. 이번 개정안은 생태계 숫자 v1과 시장·거시
그래프 v2를 분리하므로 실행 순서에는 모순이 없지만, 구현 착수 전 원본 PRD를
저장소로 동기화하거나 `docs/PRD.md`에 개정 출처와 우선순위를 명시해야 한다.

## 4. 다음 실행 순서

### 4.1 Round 3 마감

목표: Round 3.5가 의존하는 기업·분류 기반을 만든다.

1. 현재 191개 카드의 정보가치 표본 평가 — 평가 도구 완료, 실제 평가 대기
2. 자동 노출 임계값과 검토 대기 정책 조정
3. AI 공급자·월 비용 상한 결정
4. AI 요약·깊이 분류 구현
5. `companies`와 기업 후보 최소 수직 절편 구현 — 완료
6. Google 로그인·pending·승인·suspended 실환경 검증

완료 조건:

- 정보가치 상위 표본의 70% 이상이 볼 가치가 있다.
- 카드에 요약·깊이·정보가치 근거가 함께 저장된다.
- 섹터 기업 수를 집계할 수 있는 승인된 기업 집합이 존재한다.

### 4.2 Round 3.5 — 상황판 v1

목표: 카드 피드 상단에서 섹터 상태를 숫자로 파악한다.

구현:

- `indicators`
  - 코드, 이름, 단위, 지표군, 갱신 주기, 소스 설정, 활성 상태
- `indicator_values`
  - 지표, period, 값, 변화량, 기준 시각, 수집 시각, 품질 상태
- `(indicator_id, period)` unique 제약
- period 키 파서와 월·분기 경계 테스트
- 지표 카드 4개와 데이터 없음 상태
- 사용자별 표시 지표 선택

초기 지표:

| 지표 | 초기 소스 | 데이터 준비 전 처리 |
|---|---|---|
| 섹터 내 기업 수 | 승인 기업 명부 집계 | 선행 작업 완료 후 표시 |
| 벤처투자 총액 | VCS 발표치 또는 승인된 집계 | 소스 미확정 시 데이터 없음 |
| 신규 논문 | arXiv·OpenAlex | 섹터 쿼리 승인 전 데이터 없음 |
| 신규 특허 | KIPRIS Plus | 카운트 기준 승인 전 데이터 없음 |

수용 기준:

- 4종 모두 현재값과 직전 기간 대비 증감을 표시한다.
- `0`과 `데이터 없음`을 구분한다.
- 동일 period 재수집은 갱신되며 중복 행을 만들지 않는다.
- 지표 하나의 실패가 카드 피드나 다른 지표를 중단하지 않는다.
- 접근 정책은 현재 공개 읽기 정책과 별도 ADR로 확정한다.

### 4.3 Round 4–5

- 검색·필터, 기업·주제 타임라인, 원문 보관
- 메모·카드 관계·묶음
- 지표값과 같은 기간의 카드를 연결할 수 있는 관계 준비

### 4.4 Round 5.5 — 상황판 v2

목표: 추이를 탐색하고 기간을 근거로 묶음을 만든다.

구현:

- 지표 클릭 시 추이 그래프 전개
- 서로 다른 단위 최대 3종 정규화 비교
- 방향 전환 변곡점 표시
- 호버 시 값과 관련 카드 표시
- 기간 선택 시 카드 강조와 건수 배지
- 구간 코멘트로 Round 5 묶음 생성
- 시장·거시 지표 접힘 영역

시장·거시 후보:

- 환율: USD/KRW, JPY/KRW
- 국내: KOSPI, KOSDAQ
- 해외: S&P 500, NASDAQ
- 거시: GDP, 물가, 인구, 기업 생멸

시장 데이터는 소스·라이선스·갱신 주기 승인 전에는 실제값으로 표시하지 않는다.
외부 API 장애 시 마지막 정상값과 기준 시각을 표시하고 카드 피드에는 영향을 주지 않는다.
