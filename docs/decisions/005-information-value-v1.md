# 005 — 정보가치 규칙 v1

상태: 승인

일자: 2026-07-29

## 결정

AI 공급자와 비용 상한이 정해지기 전까지 요약·깊이 분류는 기존 방식으로 유지하고,
설명 가능한 규칙 기반 정보가치 평가를 먼저 도입한다.

규칙 버전 `2026-07-v1`은 다음 점수를 사용한다.

- 소스 등급: 1급 +3 / 2급 +2 / 3급 +1
- 최신성: 24시간 이내 +3 / 3일 이내 +2 / 7일 이내 +1 / 이후 0
- 중복 후보: -2

점수 구성, 한 줄 이유, 배지, 규칙 버전과 평가 시각은
`card_value_assessments`에 저장한다. 현재 화면용 결과는 `cards`에도 캐시한다.
동일 카드와 규칙 버전의 평가는 재실행 시 갱신되므로 수집 멱등성을 해치지 않는다.

배지는 총점으로 결정한다.

- 6점 이상: `major_change`
- 4~5점: `new_signal`
- 2~3점: `follow_up`
- 1점 이하: `reference`

오늘 화면은 정보가치 점수 내림차순, 발표 시각 내림차순으로 정렬한다. 평가되지 않은
기존 카드는 점수가 있는 카드 뒤에 표시한다.
