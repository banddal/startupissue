# 006 — 기업 명부 최소 수직 절편

상태: 승인

일자: 2026-08-01

## 배경

Round 3.5의 첫 생태계 지표인 “섹터 내 기업 수”는 승인된 기업 집합에 의존한다.
첫 섹터와 자동 매칭 규칙은 아직 결정되지 않았으므로, Phase 1 범위인 수동 등록과
관리자 후보 승인만 먼저 구현한다.

## 결정

- 기업은 `candidate`, `approved`, `rejected` 상태를 가진다.
- 상황판 기업 수는 향후 `approved`만 집계한다.
- 같은 섹터의 정규화된 기업명은 하나만 허용한다.
- 별칭은 기업에 저장하되 자동 매칭에는 아직 사용하지 않는다.
- 기업 후보에는 최소 하나의 검증 근거가 필요하다.
- 근거는 유형, 출처 이름, 확인일, 선택 URL·메모를 보존한다.
- 첫 섹터를 코드에 고정하지 않고 관리자가 `sector_key`를 입력한다.
- 삭제 기능은 만들지 않고 반려 상태로 이력을 보존한다.

## 수용 기준

- 관리자는 근거와 함께 기업 후보를 등록할 수 있다.
- 동일 섹터·동일 정규화 이름은 중복 등록되지 않는다.
- 관리자는 후보를 승인·반려하거나 후보 상태로 되돌릴 수 있다.
- 오늘 화면의 새 기업 후보 수는 `candidate` 행 수와 일치한다.
- 일반 사용자는 기업 관리 Server Action을 실행할 수 없다.

- 기업 병합·이름 변경 이력
