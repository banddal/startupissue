# 007 — 정보가치 표본 평가

상태: 승인

일자: 2026-08-01

## 결정

정보가치 규칙의 품질을 실제 카드 표본으로 측정하기 위해 관리자 평가를 저장한다.

- 평가는 `valuable`, `not_valuable`, `unsure` 세 상태다.
- 같은 사용자·카드는 평가 하나만 유지하며 재평가 시 갱신한다.
- 평가 당시 정보가치 점수와 규칙 버전을 스냅샷으로 보존한다.
- `unsure`는 완료 건수에는 포함하지만 유효 품질 비율의 분모에서는 제외한다.
- 품질 통과 기준은 결정된 평가 중 `valuable` 70% 이상이다.
- 품질 평가는 카드 공개·숨김 상태를 자동으로 바꾸지 않는다.

## 수용 기준

- 관리자는 정보가치 상위 카드를 순서대로 평가할 수 있다.
- 재평가는 중복 행을 만들지 않는다.
- 결정 평가 수, 보류 수, 가치 있음 비율을 조회할 수 있다.
- 표본이 없을 때 0%가 아니라 미측정 상태로 표시한다.
